Customs notes

Where this departs from the original spec

NOTED

logging/ → activity_logging/

The original spec's folder name collides with Python's own built-in logging module — anywhere that library or others internally run import logging, it would silently resolve to this folder instead of the standard library. Renamed to avoid that; responsibilities are unchanged.

NOTED

LinkedIn & Facebook: no scraping

Both platforms' Terms of Service prohibit automated scraping and actively ban accounts that attempt it. Instead, these adapters read leads a human already researched from a manual CSV — same architecture, without the ban risk.

ADDED

classification/ folder

The spec's file tree omits a folder for the AI Email Classification Module described in section 5.4 — added to actually implement what's specified.

Bill of lading — fine print

Known limitations

  • Country/company fields are inferred from unstructured text and may need manual correction.
  • No consent tracking, unsubscribe links, or CAN-SPAM/GDPR compliance layer — needed before commercial-scale use.
  • CSV storage doesn't scale to very large lead lists and has no concurrent-access safety.
  • Search-source adapters depend on page structure and are fragile to markup changes.
